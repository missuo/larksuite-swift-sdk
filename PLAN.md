### M1 — all API categories
- ✅ All 55 categories generated (1680/1680 methods), each method with a parity test.
- ✅ All 227 events typed (196 in their category module, 31 in `LarkOtherEvents`), each with an
  event test (v2/v1 envelope → `EventDispatcher` → typed decode).
- ✅ Generator hardening found while generating everything: model namespaces that would shadow
  Swift/Foundation types are suffixed (`TaskAPI`, `CalendarAPI`); modules that would collide
  with LarkCore types are suffixed (`LarkEventAPI`); service code uses fully qualified model
  types; numeric `page_token`s are converted for iterators.
- ✅ Full clean build of every module + tests: ~3 min (debug, M-series Mac); `swift test`: 1932 tests.
- ⬜ Dedicated tests for the runtime rows in §2 still marked ⬜ (ISV tokens, ClientAssertion, OAuth, options).

### M2 — cards and Channel
- ✅ `messageCard` helpers and card typings.
- ⬜ Channel module.

### M3 — scenes
- ✅ Aily, app registration.

### M4 — polish
- ✅ CI (GitHub Actions): Linux Swift 6.2 + latest, macOS, and a codegen drift check that regenerates
  from the pinned node-sdk commit. Minimum toolchain is Swift 6.2 (required by swift-crypto 5.x).
- ⬜ Skills for every module, dependency review.
